# Third-party samples

The guitar note samples used by this project are from:

- Instrument: 2017 Martin HD28 Vintage Series
- Author: Jeff Learman
- Source: sfzinstruments/Discord-SFZ-GM-Bank
- Instrument file: Discord GM/Melodic/026-Acoustic Guitar (steel).sfz
- Source commit: 05d5ed8befa042fd9d99a6d159dfc3673d3f8edc
- License stated by the source instrument: Creative Commons CC0

The build downloads the pinned sample files from the commit above and embeds them into the VST3.

The JGK interface artwork in Assets/ was created for Acoustic Guitar by JGK and is part of this project.
